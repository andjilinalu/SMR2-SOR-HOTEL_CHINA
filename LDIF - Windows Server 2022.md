# Proyecto: LDIF


## 🎯 Objetivo General

 representar las entradas del directorio LDAP en formato texto.

 ## 1️⃣ Abrir PowerShell como Administrador

Dentro de la máquina virtual:

1. Pulsa **Inicio**
2. Busca **PowerShell**
3. Clic derecho → **Ejecutar como administrador**

Verás algo similar a:

```powershell
PS C:\Windows\system32>
```
---
 ## 2️⃣ ejecutar el comando
 cuando estemos en la powershell ejecutamos el siguiente comando
 ```powerhell
ldifde -f usuarios.ldf
```
